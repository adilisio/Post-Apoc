# Post-Apoc

Deep study of the Fallout series (1, 2, 3, 4, New Vegas, 76): lore, gameplay, balance, art, music, and critical reception.

## Layout

| Path | Contents |
|---|---|
| `research/CONVENTIONS.md` | Rules every research document follows |
| `research/lore/games/` | Per-game story, locations, characters, quests, endings |
| `research/lore/universe/` | Cross-game canon: timeline, factions, vaults, creatures, technology |
| `research/gameplay/` | Per-game mechanics and balance, plus cross-game systems comparison |
| `research/reception/` | Critical and player reception: what was loved, what was disliked |
| `research/art/` | Art direction analysis and linked visual reference catalogue |
| `research/audio/` | Score, licensed music, radio, and sound design reference |
| `research/design-insights/` | Developer talks, postmortems, cut content, design philosophy |
| `research/community/` | Mods and community fixes — what players changed and why |
| `archive/` | Archived game design (`design/`), engine/3D pipeline research (`production/`), and Godot/Blender look tests (`art-test/`) |
